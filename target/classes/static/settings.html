Enterprise API credentials and secret management guidelines

🔒 Zero Secret Exposure Architecture: To protect third-party access tokens and API secrets, keys are never stored in browser memory or frontend bundles. All live integrations operate through backend environment variables:

  • APP_INTEGRATIONS_INSTAGRAM_CLIENT_ID & APP_INTEGRATIONS_INSTAGRAM_CLIENT_SECRET (Instagram Graph API)
  • APP_INTEGRATIONS_FACEBOOK_APP_ID & APP_INTEGRATIONS_FACEBOOK_APP_SECRET (Meta Graph API)
  • APP_INTEGRATIONS_YOUTUBE_API_KEY (Google YouTube Data API v3)
  • APP_INTEGRATIONS_LINKEDIN_CLIENT_ID & APP_INTEGRATIONS_LINKEDIN_CLIENT_SECRET (LinkedIn Marketing Developer API)
  • APP_INTEGRATIONS_TWITTER_BEARER_TOKEN (X API v2)

When platform environment keys are absent, SPEDO automatically switches into labeled Demo Mode, simulating full benchmark analytics and allowing risk-free evaluation.
